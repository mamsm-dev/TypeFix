# تایپ‌فیکس برای لینوکس

TypeFix ابزاری برای تشخیص اشتباه‌بودن چیدمان صفحه‌کلید هنگام تایپ انگلیسی و فارسی در لینوکس است؛ برای مثال، وقتی متن فارسی با چیدمان انگلیسی تایپ شده باشد، برنامه می‌تواند متن تبدیل‌شده را به‌عنوان پیشنهاد ارائه کند.

> **وضعیت توسعه:** هستهٔ تشخیص و مدیریت نشست در Rust و حلقهٔ رویداد foreground برای X11 پیاده‌سازی شده و آزمون‌های خودکار دارد. بااین‌حال، TypeFix هنوز یک برنامهٔ دسکتاپ کامل نیست؛ پنجرهٔ پیشنهادها، رابط سینی سیستم و جایگزینی خودکار متن هنوز پیاده‌سازی نشده‌اند.

## قابلیت‌های پیاده‌سازی‌شده

- هستهٔ مشترک تشخیص و تبدیل متن انگلیسی و فارسی.
- ماشین حالت نشست تایپ و مدیریت چرخهٔ عمر Compose و کلیدهای ترکیبی.
- دریافت رویدادهای X11/XInput2 همراه با اطلاعات modifier و گروه چیدمان فعال.
- ترجمهٔ کلیدها با XKB، پردازش Compose، مدیریت تغییر focus و به‌روزرسانی keymap.
- حلقهٔ رویداد foreground که رویدادها را پردازش کرده و actionهای نشست را به callback برنامهٔ فراخواننده تحویل می‌دهد.
- آزمون‌های یکپارچه با Xvfb، از جمله مسیر سرتاسری تبدیل نمونهٔ `sghl` به `سلام`.

## محیط دسکتاپ و مسیر توسعه

هدف نخست KDE Plasma روی X11 است و پس از آن GNOME و XFCE بررسی می‌شوند. پشتیبانی Wayland از طریق یکپارچه‌سازی با input method طراحی خواهد شد؛ ابتدا IBus و سپس Fcitx5.

مشاهدهٔ رویدادهای صفحه‌کلید در X11 محدود به یک برنامه نیست و جداسازی قابل‌اتکا بین برنامه‌ها یا تشخیص مطمئن فیلدهای گذرواژه را فراهم نمی‌کند. حلقهٔ نشست X11 فقط با اجرای صریح کاربر و در foreground فعال می‌شود. در پیاده‌سازی فعلی سرویس دارای دسترسی root، دسترسی خام به `/dev/input`، uinput یا grab سراسری ورودی وجود ندارد.

## ساخت و آزمون

پیش‌نیازها: Rust stable، ابزارهای کامپایل C، سرآیندهای توسعهٔ `libxkbcommon`، کتابخانه‌های توسعهٔ X11/XInput2، داده‌های XKB، ابزار Xvfb و برنامهٔ xdotool.

در Debian/Ubuntu:

```bash
sudo apt-get install build-essential pkg-config libxkbcommon-dev libx11-dev libxi-dev xkb-data x11-xkb-utils xvfb xdotool
```

اجرای آزمون‌های Rust:

```bash
cargo test --manifest-path linux/Cargo.toml --lib --bins
```

اجرای آزمون‌های یکپارچهٔ X11 در Xvfb:

```bash
xvfb-run -a cargo test --manifest-path linux/Cargo.toml --test x11_xvfb -- --nocapture
```

آزمون‌های یکپارچه فقط در نمایشگر مجازی و ایزولهٔ Xvfb از XTest/xdotool برای شبیه‌سازی ورودی استفاده می‌کنند. کد production کلید تزریق نمی‌کند.

بررسی پیش‌نیازهای X11:

```bash
cargo run --manifest-path linux/Cargo.toml --bin typefix-x11-probe
```

ابزار تشخیصی foreground برای مشاهدهٔ metadata رویدادها:

```bash
cargo run --manifest-path linux/Cargo.toml --bin typefix-x11-events
```

ابزار تشخیصی فقط metadata کلیدها را چاپ می‌کند، نه متن تایپ‌شده را. برای توقف آن Ctrl+C را بزنید. چون رویدادها در سطح X server قابل مشاهده‌اند، فقط هنگام آزمایش آگاهانه از آن استفاده کنید.

## حریم خصوصی و امنیت

- متن تایپ‌شده‌ای که برای تشخیص لازم است فقط در حافظه نگهداری می‌شود و log، ذخیره یا ارسال نمی‌شود.
- مسیر دریافت رویداد X11 اختیاری و فقط در foreground است و خودکار هنگام شروع سیستم فعال نمی‌شود.
- سرویس root، دسترسی خام evdev، uinput یا input grab وجود ندارد.
- وضعیت نشست هنگام تغییر focus، پیمایش، میان‌برها، لغو عملیات و رویدادهای مرتبط پاک‌سازی می‌شود.
- X11 امکان تشخیص مطمئن فیلد گذرواژه یا جداسازی کامل برنامه‌ها را فراهم نمی‌کند. اگر این محدودیت پذیرفتنی نیست، مشاهدهٔ رویدادهای X11 را فعال نکنید.
- رابط دسکتاپ و جایگزینی خودکار متن هنوز پیاده‌سازی نشده‌اند.
