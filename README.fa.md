# تایپ‌فیکس برای لینوکس

TypeFix ابزاری برای تشخیص اشتباه‌بودن چیدمان صفحه‌کلید هنگام تایپ انگلیسی و فارسی در لینوکس است؛ برای مثال، وقتی متن فارسی با چیدمان انگلیسی تایپ شده باشد، برنامه می‌تواند متن تبدیل‌شده را به‌عنوان پیشنهاد ارائه کند.

> **وضعیت توسعه:** TypeFix یک پنجرهٔ تنظیمات (`typefix-gui`، با GTK 3، تم روشن و تیره با رنگ اصلی #18B0B0 و رابط فارسی/انگلیسی) و یک برنامهٔ خط فرمان (`typefix`) دارد. متن را انتخاب کنید و با یک میان‌بر قابل‌تنظیم آن را بین چیدمان انگلیسی و فارسی تبدیل کنید. هنوز یک برنامهٔ دسکتاپ کامل نیست (بدون آیکون سینی سیستم و بدون پشتیبانی Wayland) و روی دسکتاپ واقعی فقط به‌صورت محدود آزموده شده است.

## قابلیت‌های پیاده‌سازی‌شده

- هستهٔ مشترک تشخیص و تبدیل متن انگلیسی و فارسی.
- ماشین حالت نشست تایپ و مدیریت چرخهٔ عمر Compose و کلیدهای ترکیبی.
- دریافت رویدادهای X11/XInput2 همراه با اطلاعات modifier و گروه چیدمان فعال.
- ترجمهٔ کلیدها با XKB، پردازش Compose، مدیریت تغییر focus و به‌روزرسانی keymap.
- حلقهٔ رویداد foreground که رویدادها را پردازش کرده و actionهای نشست را به callback برنامهٔ فراخواننده تحویل می‌دهد.
- پنجرهٔ تنظیمات `typefix-gui`: ضبط میان‌بر جدید، روشن/خاموش کردن پیشنهاد حین تایپ، انتخاب تم (سیستم/روشن/تیره) و زبان رابط؛ بستن پنجره TypeFix را در پس‌زمینه فعال نگه می‌دارد.
- برنامهٔ foreground با نام `typefix`: با یک میان‌بر سراسری قابل‌تنظیم، متن انتخاب‌شده را بین چیدمان انگلیسی و فارسی تبدیل می‌کند (نگاشت چیدمان از چیدمان‌های فعال XKB ساخته می‌شود). حالت اختیاری `--suggest` پیشنهادهای حین تایپ را با `notify-send` نشان می‌دهد.
- بسته‌های نصب (AppImage، `.deb`، `.rpm` و Arch) که CI می‌سازد و در بخش Releases گیت‌هاب منتشر می‌شوند.
- آزمون‌های یکپارچه با Xvfb، از جمله مسیر سرتاسری تبدیل نمونهٔ `sghl` به `سلام`.

## محیط دسکتاپ و مسیر توسعه

هدف نخست KDE Plasma روی X11 است و پس از آن GNOME و XFCE بررسی می‌شوند. پشتیبانی Wayland از طریق یکپارچه‌سازی با input method طراحی خواهد شد؛ ابتدا IBus و سپس Fcitx5.

مشاهدهٔ رویدادهای صفحه‌کلید در X11 محدود به یک برنامه نیست و جداسازی قابل‌اتکا بین برنامه‌ها یا تشخیص مطمئن فیلدهای گذرواژه را فراهم نمی‌کند. حلقهٔ نشست X11 فقط با اجرای صریح کاربر و در foreground فعال می‌شود. در پیاده‌سازی فعلی سرویس دارای دسترسی root، دسترسی خام به `/dev/input`، uinput یا grab سراسری ورودی وجود ندارد.

## نصب

یکی از بسته‌ها را از [آخرین ریلیز](https://github.com/mamsm-dev/TypeFix/releases/latest) دانلود کنید (فقط x86_64) و با `SHA256SUMS` بررسی کنید:

```bash
# Debian / Ubuntu
sudo apt install ./typefix_0.3.0-1_amd64.deb
# Fedora / openSUSE
sudo dnf install ./typefix-0.3.0-1.x86_64.rpm
# Arch Linux
sudo pacman -U typefix-0.3.0-1-x86_64.pkg.tar.zst
# AppImage (هر توزیع)
chmod +x typefix-0.3.0-x86_64.AppImage && ./typefix-0.3.0-x86_64.AppImage
```

در ریلیز یک بستهٔ `typefix-debug` برای Arch هم هست که نمادهای اشکال‌زدایی دارد و نیازی به نصبش نیست.

## استفاده

### پنجرهٔ تنظیمات

**TypeFix** را از منوی برنامه‌ها اجرا کنید (یا `typefix-gui` را بزنید). این پنجره میان‌بر فعال را نشان می‌دهد و امکان این کارها را می‌دهد:

- **تغییر میان‌بر:** روی «تغییر میان‌بر» بزنید و ترکیب کلید دلخواه را فشار دهید (حداقل یکی از Ctrl، Alt، Shift یا Super لازم است؛ Esc لغو می‌کند). اگر برنامهٔ دیگری از همان ترکیب استفاده کند، میان‌بر قبلی فعال می‌ماند و پنجره مشکل را توضیح می‌دهد.
- **روشن/خاموش کردن «پیشنهاد هنگام تایپ»** و انتخاب اینکه متن با کدام چیدمان تایپ شده است.
- **انتخاب تم** (پیروی از سیستم، روشن یا تیره) و **زبان رابط** (English یا فارسی، همراه با چیدمان راست‌به‌چپ).

تنظیمات در `~/.config/typefix/config` ذخیره می‌شود و با `typefix` خط فرمان مشترک است. بستن پنجره آن را فقط پنهان می‌کند و TypeFix در پس‌زمینه به تبدیل ادامه می‌دهد؛ برای نمایش دوباره TypeFix را دوباره اجرا کنید یا برای توقف روی «خروج» بزنید. هنوز آیکون سینی سیستم و اجرای خودکار نداریم: برای اجرا هنگام ورود، `typefix-gui` را به برنامه‌های شروع (startup) دسکتاپ خود اضافه کنید.

### خط فرمان

پیش‌نیازها: نشست X11 (نشست فقط‌Wayland هنوز پشتیبانی نمی‌شود)، ابزار `setxkbmap`، و تنظیم‌بودن هم چیدمان انگلیسی (US) و هم چیدمان فارسی (`ir`) در تنظیمات صفحه‌کلید. نصب `notify-send` (بستهٔ `libnotify`) توصیه می‌شود؛ بدون آن پیشنهادها در ترمینال چاپ می‌شوند.

```bash
typefix                                # حالت میان‌بر، پیش‌فرض Ctrl+Alt+Space
typefix --shortcut "Super+Shift+F9"    # استفاده از میان‌بر دیگر
typefix --suggest                      # پیشنهاد تبدیل حین تایپ هم فعال شود
```

`typefix` تا زدن Ctrl+C در foreground اجرا می‌شود. **در هر برنامه‌ای متن را انتخاب کنید و میان‌بر را بزنید**: متنی که با چیدمان انگلیسی تایپ شده (مثلاً `sghl`) با متن فارسیِ همان کلیدها (`سلام`) جایگزین می‌شود و متن فارسی به چیدمان انگلیسی برمی‌گردد. جهت تبدیل از خود متن انتخاب‌شده تشخیص داده می‌شود.

**میان‌بر دلخواه.** از `--shortcut` استفاده کنید یا فایل `~/.config/typefix/config` را بسازید:

```
# ~/.config/typefix/config
shortcut = Ctrl+Alt+Space
suggest = false
```

میان‌بر یک یا چند کلید تغییردهنده (`Ctrl`، `Alt`، `Shift`، `Super`) به‌همراه یک کلید با نامی مثل `Space`، `F9`، `c` یا `Return` است که با `+` به هم وصل می‌شوند. گزینه‌های خط فرمان بر فایل تنظیمات اولویت دارند. اگر برنامهٔ دیگری از همان ترکیب استفاده کند، `typefix` اعلام می‌کند که نتوانسته آن را بگیرد.

نحوهٔ کار: متن انتخاب‌شده از selection سیستم X خوانده می‌شود، در حافظه تبدیل می‌شود، در selection و کلیپ‌بورد قرار می‌گیرد و با Shift+Insert ساختگی جایگذاری می‌شود (در برنامه‌های GTK/Qt، مرورگرها و ترمینال‌ها کار می‌کند). متن قبلی کلیپ‌بورد بعد از آن برگردانده می‌شود. برنامه‌هایی که Shift+Insert را نادیده می‌گیرند جایگزین نمی‌شوند.

حالت `--suggest` علاوه بر این تایپ را هم زیر نظر می‌گیرد: کلمه‌ای را با چیدمان اشتباه تایپ کنید و Space بزنید تا متن تبدیل‌شده به‌صورت اعلان نمایش داده شود (چیزی جایگزین نمی‌شود). این حالت `--source en|fa` و `--data-dir DIR` (یا `TYPEFIX_DATA_DIR`) را هم می‌پذیرد. گزینه‌های دیگر: `--help` و `--version`.

## ساخت و آزمون

پنجرهٔ تنظیمات پشت ویژگی `gui` در cargo است و به فایل‌های توسعهٔ GTK 3 نیاز دارد (در Debian/Ubuntu بستهٔ `libgtk-3-dev`):

```bash
cargo build --manifest-path linux/Cargo.toml --features gui --bin typefix-gui
```

پیش‌نیازها: Rust stable، ابزارهای کامپایل C، سرآیندهای توسعهٔ `libxkbcommon`، کتابخانه‌های توسعهٔ X11/XInput2، داده‌های XKB، ابزار Xvfb و برنامهٔ xdotool.

در Debian/Ubuntu:

```bash
sudo apt-get install build-essential pkg-config libxkbcommon-dev libx11-dev libxi-dev xkb-data x11-xkb-utils xvfb xdotool
```

اجرای آزمون‌های Rust:

```bash
cargo test --manifest-path linux/Cargo.toml --lib --bins
```

اجرای آزمون‌های یکپارچهٔ X11 در Xvfb:

```bash
xvfb-run -a cargo test --manifest-path linux/Cargo.toml --test x11_xvfb -- --nocapture
```

آزمون‌های یکپارچه فقط در نمایشگر مجازی و ایزولهٔ Xvfb از XTest/xdotool برای شبیه‌سازی ورودی استفاده می‌کنند. کد production کلید تزریق نمی‌کند.

بررسی پیش‌نیازهای X11:

```bash
cargo run --manifest-path linux/Cargo.toml --bin typefix-x11-probe
```

ابزار تشخیصی foreground برای مشاهدهٔ metadata رویدادها:

```bash
cargo run --manifest-path linux/Cargo.toml --bin typefix-x11-events
```

ابزار تشخیصی فقط metadata کلیدها را چاپ می‌کند، نه متن تایپ‌شده را. برای توقف آن Ctrl+C را بزنید. چون رویدادها در سطح X server قابل مشاهده‌اند، فقط هنگام آزمایش آگاهانه از آن استفاده کنید.

## حریم خصوصی و امنیت

- متن تایپ‌شده‌ای که برای تشخیص لازم است فقط در حافظه نگهداری می‌شود و log، ذخیره یا ارسال نمی‌شود.
- حالت میان‌بر فقط همان یک ترکیب کلید را می‌گیرد و کلیدهای دیگر را زیر نظر نمی‌گیرد. مشاهدهٔ تایپ (`--suggest`) اختیاری، فقط در foreground و به‌طور پیش‌فرض خاموش است.
- متن انتخاب‌شده فقط هنگام زدن میان‌بر خوانده می‌شود، فقط در حافظه می‌ماند و برای لحظه‌ای جای کلیپ‌بورد را می‌گیرد (متن قبلی برگردانده می‌شود). برنامه‌های دیگری که کلیپ‌بورد را زیر نظر دارند ممکن است آن را ببینند.
- برای جایگذاری فقط یک Shift+Insert ساختگی با XTest فرستاده می‌شود. سرویس root، دسترسی خام evdev یا uinput وجود ندارد.
- وضعیت نشست هنگام تغییر focus، پیمایش، میان‌برها، لغو عملیات و رویدادهای مرتبط پاک‌سازی می‌شود.
- X11 امکان تشخیص مطمئن فیلد گذرواژه یا جداسازی کامل برنامه‌ها را فراهم نمی‌کند. اگر این محدودیت پذیرفتنی نیست، مشاهدهٔ رویدادهای X11 را فعال نکنید.
- هنگام نمایش پیشنهاد، کلمهٔ اصلی و کلمهٔ تبدیل‌شده به `notify-send` و در نتیجه به سرویس اعلان دسکتاپ شما داده می‌شود و ممکن است در تاریخچهٔ اعلان‌ها بماند. خود TypeFix آن‌ها را ذخیره نمی‌کند.
- سینی سیستم پیاده‌سازی نشده و Wayland پشتیبانی نمی‌شود.

## ساختار پروژه

- `linux/`: هستهٔ Rust، backend مربوط به X11، برنامه‌های `typefix` و `typefix-gui`، فایل‌های بسته‌بندی، مستندات نشست و مدل امنیتی.
- `.github/workflows/`: `linux-core.yml` (آزمون‌ها) و `linux-release.yml` (با push تگ `v*` بسته‌ها را می‌سازد و ریلیز گیت‌هاب منتشر می‌کند).
- `Resources/en_50k.txt` و `Resources/fa_50k.txt`: داده‌های فراوانی واژه‌های انگلیسی و فارسی.
- `assets/`: تصاویر و رسانه‌های پروژه.
